## Informal proof
{{
Step 1: Unfold the internal representation Let L = alist_of q. From assumption ¬ is_empty q and the definition is_empty q ≡ (alist_of q = []), we directly obtain L ≠ [].
Step 2: Express the minimum element and its priority Because L ≠ [], its head is defined. Write (m, p_min) = hd L. By the definition min q ≡ fst (hd (alist_of q)), we have min q = m. Since the pair (m, p_min) belongs to set L (by the fact that the head of a non‑empty list is in the list), and L satisfies the invariant distinct (map fst L), the function map_of L maps each key to at most one value. Thus priority q m = map_of L m = Some p_min.
Step 3: Characterise an arbitrary value v present in the queue The assumption v ∈ set |q| together with values q = map fst (alist_of q) yields v ∈ set (map fst L). Hence there exists a pair (v, p_v) ∈ set L. By the distinctness of keys in L (the type invariant), this pair is unique for the key v. Consequently priority q v = map_of L v = Some p_v.
Step 4: Exploit the sortedness invariant The type invariant of pri_queue guarantees that sorted (map snd L) holds, i.e. the list L is sorted in non‑decreasing order of priorities. For a non‑empty list sorted by a projection f, the head gives the minimal f value among all elements. More precisely: ∀ (a,b) ∈ set L. snd (hd L) ≤ b. Applying this to the pair (v, p_v) ∈ set L we obtain p_min ≤ p_v.
Step 5: Translate the obtained inequalities to the the-expressions From Step 2 we have priority q (min q) = Some p_min, therefore the (priority q (min q)) = p_min. From Step 3 we have priority q v = Some p_v, therefore the (priority q v) = p_v. Step 4 establishes p_min ≤ p_v.
Step 6: Conclude the desired inequality Combining the equalities of Step 5 with the inequality of Step 4 gives exactly the theorem's statement: the (priority q (min q)) ≤ the (priority q v).

{{

Step 2: Relate the priority of the pushed queue to the original queue.By the definition of `priority`, priority (push k p q) = map_of (alist_of (push k p q)).Through the previous step's result, we have `alist_of (push k p q) = alist_of q`.Thus, priority (push k p q) = map_of (alist_of q) = priority q`.
Step 3: Apply the functions to the key `k`.From Step 2 we obtain the equality of the functions `priority (push k p q)` and `priority q`.In particular, for the key `k`, priority (push k p q) k = priority q k`,which is exactly the statement of the theorem.
